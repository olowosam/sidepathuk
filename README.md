# SidePathUK

A client-facing landing page and interactive demo for SidePathUK, an AI assistant concept for UK estate agencies.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s in the first version

- Responsive marketing landing page with a dark navy and lime visual identity
- Interactive demo chat with sample property enquiry, viewing, and human hand-off flows
- Sample lead dashboard preview
- Calls to action via email

The chat is a front-end demonstration only: it does not call an AI model, send messages, store leads, or book real viewings. All listings and lead records shown are fictional. Real AI, calendar, CRM, messaging, and booking connections should be configured and tested with each client before being advertised as live.

Property photographs are loaded from Unsplash URLs and require an internet connection. Replace these with licensed brand assets before production if desired.
